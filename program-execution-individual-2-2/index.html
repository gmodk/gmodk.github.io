program_execution_individual::(2/2)

... program_execution_individual::(1/2)

 

  • If a system develops from a set of initial specifications, what structures could distinguish between predeterminated information and genuinely path-dependent organization?

  • What invariants would have to persist through development for we to say that one evolving system remains numerically the same individual?

 

a) Set up

Let the function \(\phi: P x C \to R\) to map a tuple \((p,c)\) to a realization \(r\), where \(p \in P\) is a program and \(c \in C\) is a contingency (history).

Let the map \(H_{\alpha}: R \to D_{\alpha}\) to extract the organization into some descriptive level. Then, we have:

$$ H_{\alpha}(P,C) = H_{\alpha}(\phi(p,c)) $$

which is the realized organization along a particular path.

 

b) Formally

The path-dependent part is the variation of the \(H_{\alpha}\) over \(C\). If \(C\) has a probability measure \(\mu\), we define its predictable component by:

$$ \bar{H}_{\alpha}(p) = \int_{c}^{\infty} H_{\alpha}(p,c) \, d{\mu(c)} = E[H_{\alpha} | P = p] $$

And the path-dependent derivation by:

$$ \Delta_{\alpha}(p,c) = H_{\alpha} - \bar{H}_{\alpha}(p-c) $$

 

c) Conclusion

We conclude, therefore that:

$$ H_{\alpha}(p,c) = H_{\alpha}(p) + \Delta_{\alpha}(p,c) $$

where: - \(H_{\alpha}(p)\) is the predictable path from \(p\).

  • \(\Delta_{\alpha}(p,c)\) is the history dependant path.

But the integral represents an expected or predictable component, not necessarily strcited predetermined information, which would required invariance across all \(c \in C\).

 

d) Intuitevely

The program defines what can systematically be expected across all possible histories, while (\(H_{\alpha}(p) \circ \phi\)) captures what actually emerges in one particular history.

Averaging over \(C\) extracts the common predictable structure, and the contribution of the specific path to the representation is recored by the resisudal.
