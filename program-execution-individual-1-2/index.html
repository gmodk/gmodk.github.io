program_execution_individual::(1/2)

Sat 10 October 2026

  • What mathematical distinctions would we need to separate a Program, its Execution, and an emergent Individual without assuming in advance that these are three different ontological kinds?

 

a) Set up

Let \(P\) be a genrative structure, \(C\) the space of initial conditions or contingences, and \(I\) the space of possible realizations. We define a map \(\phi: P x C \to I\):

Supose \(R = Im(\phi)\) is the set of realizable executions. A level of description is then given by a structure preserving map:

$$ H_{\alpha}: R \to D_{\alpha} $$

with \(R = Im(\phi) \subseteq I\) and \(\phi(P,C) = i\)

 

b) Formally For each descriptive map \(H_{\alpha}\), we define:

$$ r_1 ~ r_2 <=> H_{\alpha}(r_1) = H_{\alpha}(r_2) $$

Then, the descriptive level is the quotient:

$$ D_{\alpha} \cong \frac{R}{r_{\alpha}} $$

This is equivalent to:

$$ \frac{R}{Ker H_{\alpha}} \cong Im H_{\alpha} $$

 

c) Conclusion

The program, its execution and the emergent individual need not to be three different ontological kinds. They can be understood as different mathematical roles within one structure, where:

  • P specifies possibilites.

  • R contains realized trajectories.

  • An individual can be represented as an equivalence class \([r_{\alpha}]\) at a chosen description level \(D_{\alpha}\).

 

d) Intuitevely

The idea is that a system contains more detail that any description of that system prserveres. The map \(\phi\) generates actual realizations from the program, while each \(H_{\alpha}\) forgets some distinctions and keeps others.

Two different realizations may tehrefore count as the same individual whenerver they become identical under the chosen description, so individuality emerges from the structure we preserve across transformations rather than being assumed beforehand.
